# Design styles

Brave's product design guidelines, written so that developers and their coding agents can apply
them in any repository and keep every surface at the same design standard.

The guidelines cover where design values come from ([Nala](https://github.com/brave/leo/), Brave's
design system), which platform conventions each surface follows (Chromium desktop, Android,
iOS and separate apps), how UI text is written and localized, and what to check before calling a
surface done.

## Guidelines

- [Product design](product-design.md)

## Using them with an agent

Point your agent at [`product-design.md`](product-design.md), for example by referencing it from
your repository's `CLAUDE.md`, `AGENTS.md` or equivalent agent instructions, or by copying it into
your repository. The file starts with a "Using this file" section that tells the agent how to
apply it.
